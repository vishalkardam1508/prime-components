---

## 🧩 Components

### 📊 Nova Excel

A spreadsheet component that brings an Excel-like experience to your web app.

- Supports **React**, **Angular**, **Vue.js** and **HTML/CSS**
- Familiar spreadsheet editing your users already know
- Drop it into any project, whatever the framework

### ⚡ Nova Virtual Scroll Grid

**Stop using boring pagination grids.** Nova Virtual Scroll Grid renders only the
rows on screen, so users can scroll through huge datasets smoothly without clicking
through pages.

- Virtual scrolling for large datasets
- Fully featured data grid
- A faster, smoother alternative to paginated tables

### 📝 Nova Wordpad

A rich text editor for writing and formatting content directly in the browser.

- Word-processor style editing
- Easy to embed in forms, CMSs and dashboards
